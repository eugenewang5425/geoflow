# 1 项目背景

本课程的大数据与云计算大作业要求围绕分布式计算完成一个可运行的项目。在前期课程的学习与实验中，我基于 Hadoop 搭建过实验集群：使用 VMware 在一台主机上部署了三台 Linux 虚拟机（主机名 hadoop100、hadoop101、hadoop102），安装 Hadoop 3.1.3，分别配置为主节点和两个数据节点。由于三台虚拟机的开机与系统初始化耗时并不固定，节点进程的启动顺序会直接影响 NameNode 与 DataNode 的注册和集群的就绪状态，我为这套环境自写了集群启动脚本——脚本通过 SSH 逐台拉起各节点的 HDFS、YARN 与 HistoryServer 守护进程，并配合 xsync 分发配置、jpsall 汇总各节点进程状态，最终组成了一个简单的分布式 HDFS 架构，可以完成文件在集群中的分块存储、副本冗余与读取。

这个实验集群让我实际看到了 HDFS 的工作方式：文件被切块后分布在多个节点上，副本机制使单个节点失效后数据仍然可用，NameNode 只维护元数据而不存数据本体。不过当时的数据集主要来自测试文件，数据量很小，计算部分也没有真正在集群上调度执行，离"大数据分析"还有不小的距离。

本次大作业选择在此基础上走通一条更完整的分布式分析链路：以纽约市 2025 年 1 月黄色出租车出行记录（约 347.5 万条，来源为纽约市出租车与轿车管理局 TLC 公开数据）为数据源，完成数据导入、HDFS 分布式存储、YARN 调度下的 MapReduce 时空统计、结果独立校验和网页可视化，同时记录作业日志、集群状态与对照实验数据，作为分析和评价分布式计算过程的依据。
